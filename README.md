# Email Spam Classifier

## Overview
Email Spam Classifier is a Machine Learning web application built using Python and Streamlit. The application classifies incoming messages as **Spam** or **Ham (Not Spam)** based on their content.

## Features
- Detects spam and non-spam messages
- Interactive Streamlit user interface
- Text preprocessing and cleaning
- Machine Learning-based prediction
- Fast and easy-to-use web application

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Natural Language Processing (NLP)

## Dataset
The model is trained using a spam/ham email dataset containing labeled messages for classification.
